# Direitos das músicas e do código — pendência RH-002

O repositório contém áudio de terceiros. **O fato de um arquivo estar no GitHub não
concede licença para transmissão pública, cópias offline ou redistribuição.**
A autorização precisa ser conferida individualmente para cada gravação e obra.

## Ficha obrigatória por faixa

| Campo | Informação a registrar |
| --- | --- |
| ID estável / caminho | Faixa do `catalogo.json` |
| Composição / intérprete | Identificação da obra e gravação |
| Titular(es) | Direitos autorais e fonográficos |
| Fonte da autorização | Contrato, licença explícita ou termo de uso |
| Streaming público | Permitido / proibido / não verificado |
| Download pelo usuário | Permitido / proibido / não verificado |
| Cache e distribuição Android | Permitido / proibido / não verificado |
| Abrangência territorial e prazo | Países, expiração, eventuais restrições |
| Comprovante | Local seguro do documento, sem publicar dados privados |

## Estado desta revisão

A auditoria v1.6 indicou 64 faixas e somente seis com
`downloadAllowed: true` nos dados, embora a interface permitisse baixar todas.
Não foi fornecida documentação de licenças verificável para essas 64 músicas.
Este relatório **não certifica** distribuição autorizada. A regularização dos
direitos e eventual bloqueio de faixas sem licença requer validação do responsável.

A licença do **código** é separada dos direitos do **catálogo de áudio**.
Não aplicar uma licença open source às gravações sem autorização específica.
